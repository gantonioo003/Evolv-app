# Catalogos de entidades

Snapshots locais e versionados usados pelo extrator. Eles existem para que
treino, testes e inferencia sejam reproduziveis sem depender de uma conexao ao
Supabase. Os nomes de exercicios e alimentos seguem os catalogos do produto;
sinonimos sao mantidos explicitamente.

Uma atualizacao exige nova versao, validacao de aliases duplicados e execucao
completa dos testes de entidades.
